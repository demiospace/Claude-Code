# Entwurf v3 – manibase-Startseite (Mockup)

`manibase-redesign.html` ist der aktuelle Design-Entwurf als **self-contained Mockup**:
Fonts (Sora, Hanken Grotesk) und Bilder (Signet, Helfer-Illustrationen, Gründerfotos) der
Live-Seite sind als data-URIs eingebettet — die Datei läuft ohne Internet in jedem Browser.

Gelb gestrichelte Stellen mit **PLATZHALTER**-Badge markieren Fakten, die vor dem Launch
durch echte Angaben ersetzt werden müssen (Liste: [docs/design-kompendium.md](../docs/design-kompendium.md),
Abschnitt 5, sowie im Anhang des Mockups selbst).

Das Mockup ist kein Produktionscode: Links zeigen teils auf `#`, Formulare senden nichts.
Die Umsetzung als echte statische Seite folgt nach Freigabe.
